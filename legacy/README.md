# 📜 Legacy Infrastructure & Scripts

Este diretório contém artefatos da arquitetura anterior baseada em **Virtual Machines (VM) com Docker Compose**.

## ⚠️ Aviso de Uso
Estes arquivos são mantidos apenas para **referência histórica** ou para possibilitar testes locais rápidos fora do cluster.
Eles **NÃO** são utilizados nos pipelines de CI/CD atuais nem são refletidos no ambiente de produção (AKS/ArgoCD).

## 🗂️ Conteúdo
- `docker-compose/`: Configurações originais para orquestração local/VM.
- `vm-scripts/`: Scripts de deploy e manutenção direta no servidor legado.
